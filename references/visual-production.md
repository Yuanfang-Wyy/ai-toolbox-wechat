# 图与封面制作

用于原创说明图和封面检查，不代替真实软件截图。默认保持米白 `#faf8f2`、橙色 `#ff642a`、深色文字，用户本次参考与明确风格优先；不启用第三方出图 API。已有工具能准确完成时直接用，不为选择样式增加审批。内容提炼和素材取舍另见 [内容与视觉适配](content-craft.md)。

## 选择当前需要的能力

先分析正文哪些地方需要读者看见成果、找到入口或理解关系，记录图位和该图要回答的问题。实际界面和结果优先用真实截图；执行顺序、比较条件与数据关系优先用准确可编辑的说明图。抽象观点仍不容易理解时，才补插画，一图只表达一个概念；不为补足数量重复装饰同一个意思。

| 需要的结果 | 按需调用 | 在本号中的用法 |
|---|---|---|
| 文章中的概念、隐喻或场景插画 | `baoyu-article-illustrator` | 从正文选图位，确定信息类型、画法与配色，保存逐图提示词后用原生图像能力生成 |
| 原创文章封面 | `baoyu-cover-image` | 分别决定主题、构图、配色、短标题与情绪，按横图和方图各自检查 |
| 准确流程、条件或前后对照 | 已有关系图制作能力 | 以可追溯事实组织节点与关系，保留可编辑源文件 |

两个补充 Skill 按宿主已安装的技能清单定位，读取当前需要的子 Skill 和参考即可，不加载整套工具包。没有安装时可用现有工具完成任务；没有实际图像生成工具时只能交付规划和提示词，不能宣称已生成图片。

上游的默认图数、首次配置及每次风格确认不覆盖当前任务和已有授权。沿用本号规范选择合理默认，不因缺少 `EXTEND.md` 停下或自动创建另一套配置。原创位图仅调用当前宿主原生 `image_gen` / `imagegen`，遵守其实际工具协议；不安装 `baoyu-image-gen`、Bun 或 CLI wrapper，不自动切换付费 API 或复用其他模型凭证。原生工具缺失时保留每图完整提示词、建议比例及图位，交接待生成项。

每个生成提示词与正文版本关联并先保存，改图另存新版本。保留原图，不运行上游删除文件或删除配置的指令；整个文件确需删除时使用系统废纸篓。上游文档只作为内部参考，正文不粘贴其操作指令、许可说明或模板全文，来源和许可在内部来源记录中维护。

## 从正文中选一个值得画的关系

先写清这张图要回答的问题，再提取必要节点与关系。图中文字、结论和数字必须有本篇来源；不把尚未验证的能力画成已完成结果。

| 内容关系 | 适合的图 | 需要检查 |
|---|---|---|
| 输入、动作、输出有依赖 | 流程图 | 顺序、分支条件与验收出口 |
| 改进会返回前一步 | 循环图 | 每条回路的真实触发条件 |
| 分类、组成或上下级 | 层次图 | 不把分类关系画成执行顺序 |
| 同任务的两种方法 | 并列对照 | 使用相同输入与评价条件 |
| 两个维度影响选择 | 矩阵 | 维度确实可区分，不凭空赋分 |
| 结论由几项事实支持 | 递进/证据图 | 因果有证据，推测与事实分开 |

复杂关系可以拆图，不把正文所有信息塞进一张。准确的流程、文字和数据优先用可编辑 SVG；原生生图只用于确有解释价值的插画，并按环境额度与用户授权执行。不能生成仿真软件窗口、按钮、数值或使用结果作为证据；示例数据须有依据并明确标为示例，不画成产品已输出的事实。

## 制作与阅读核查

按关系选择布局，保留 SVG 源文件并导出实际可打开的 PNG/JPEG。节点使用短语，箭头避开文字，必要条件紧贴相关动作。字号由最终手机宽度决定：例如 1080px 宽图片显示为 360px 时，36px 源字号才约等于 12px；读不清时放大字体、减少节点或拆图，不只检查画布像素。

图注写清“流程示意”“编辑示例”或“本次实测截图”，后者须有操作证据。关键提示词和步骤仍留为可复制正文。可从 [流程示意示例](../assets/workflow-example.svg) 修改布局，该示例不是任何软件的实测结果。

检查文字、关系、缩小后的可读性和正文图位；导出的图片还须满足视觉标准中的传输限制。保留本地 HTML/SVG 不等于图片已进入微信，也不默认公开托管用户材料。

## 封面检查

先提炼本篇读者要完成的任务，再决定主题对象、构图、配色、文字量和情绪。默认米白橙色与深色字，不把每篇封面锁成同一张底图换标题；用户给出的参考、用途与可读性要求优先。实际截图可以作为封面主体，插画不能暗示软件已跑出某种结果。

文章标题与封面短标题可以不同，短标题只保留识别任务所需的词。核心任务词与主体放在中央，横图和方图分别检查，必要时为方图重新构图和缩短标题，不把完整长标题硬挤入方形。2.35:1 横图的中心 1:1 方形约占全宽 42.6%；这是检查用几何区域，不保证每个微信入口采用同一裁切。两侧可以放装饰和次要说明，但缺少它们仍应看懂主题。

使用 [封面模板](../assets/cover-layout.svg) 或本次封面生成离线预览：

```bash
# 在总入口 Skill 根目录运行
python3 scripts/preview_cover.py --image assets/cover-layout.svg --output /tmp/cover-review.html
```

脚本读取本地 PNG/JPEG/SVG，生成自包含 HTML；不改原图、不上传、不调用模型。已有输出文件不会覆盖，改稿另用新输出名。打开 HTML 分别看完整横图、中心方形、安全区和两种缩略图，核查：核心词有没有被截断、主体是否保留、字是否看得清、图是否真的说明本篇任务。

脚本读取图片头部尺寸、检查比例并计算几何范围，不完整解码像素、不做 OCR、不判断错别字或标题语义。图片能否完整打开另以实际渲染核查。记录“尺寸检查”“本地裁切人工核查”“微信手机核查”各自完成状态，未做的一项不能标通过。

当前草稿连接没有 `cover`/`theme` 参数。新封面只能先作为本地成果交付，再通过本人后台或另行授权的可用接口更换；HTML 预览不能直接变成云端正文主题。
