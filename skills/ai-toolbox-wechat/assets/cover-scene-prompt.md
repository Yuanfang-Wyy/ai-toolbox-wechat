# 场景封面提示词模板

按当篇填充，不把方括号占位文字交给生图。原生imagegen为默认后端，逐图完整提示词与原件保存在该稿私有工作目录；不把实际逐稿提示词、草稿或台账打入公开包。

```text
制作一张公众号文章封面，横版2.35:1，约1920×818或更高分辨率。
风格：现代编辑插画，纸张拼贴/纸雕或克制的立体材质，亮钴蓝、薄荷绿和米白，深蓝粗体标题，少量暖色点缀。
文章的唯一典型任务：[输入、动作和成果]。
场景隐喻：[与任务有直接关系的具体对象和变化，例如混合音波分成两条音轨]。
不要画假软件截图，不添加未经验证的数据或效果承诺。不要空心方框、随机圆点、重复占位卡片。
完整主标题必须逐字为：[实际文章完整标题，保留工具名 - 后半句]。
账号标识：AI顺手工具箱。
标题是视觉重心，实际缩到350—390像素宽也要可读。根据实际文字宽度换行，不固定四行；英文词不拆断，行首不落结束标点。
所有标题和账号标识尽量位于画布中央约38%宽度，左右留给场景插画；2.35:1图片的中心方形只占宽度约42.6%，不能把48%误认为安全区。
文字深色高对比，背景有真实材质和画面层次，主体不要遮住文字。留白应帮助阅读，不是大片无意义空白。
不增写副标题、免费/最快/最好等宣传语，不复制本参考图的工具名或内容。
```

出图后实际看横图、中心1:1裁切和手机缩略图；标题溢出、错字或不清晰时重新调用原生生图调整，不用代码涂白重写。只允许必要的缩放、压缩、格式转换与裁切导出，不以代码替代本规则的插画生成。OCR是辅助检查，英文I/l及中文误识别须人工看原图。
